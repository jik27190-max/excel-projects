# Excel Projects by Prakash Kumar

Excel, VBA and PowerPoint projects by Prakash Kumar, B.Com (Hons) student at DU SOL, New Delhi.

## Projects

- **Mini ERP System**: Linked Excel sheets for employees, customers, inventory, sales and payroll, with VBA macros.
- **Excel Quiz Center**: Quiz app with auto scoring and weak-topic analysis.
- **Decision Maker**: Ranks options using weighted criteria, with charts.
- **Excel Shortcuts and Formulas Guide**: 25-slide cheat sheet with worked examples.
- **Snake Game in Excel**: Playable game built with VBA macros.
- **Presentations**: "Modern Agriculture" and "The Sun".

## How to open

Download the file and open it in Excel. For the .xlsm files, click **Enable Content** to run the macros.
